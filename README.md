# Site da Novix Tecnologia

Site estático de apresentação da Novix. Todo contato vai para o WhatsApp, e o site não guarda nenhum dado.

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # lint + lint tipado + tipos + testes + build
npm run build    # gera out/
npm start        # serve out/ localmente
```

- O que o site faz e o que falta confirmar: [PRODUCT.md](PRODUCT.md)
- Mudar textos, preços e contatos: `config/empresa.json`
- Trabalhos do portfólio: `config/portfolio.json`
